# 六级背单词 App —— 设计规格与里程碑

> 项目根目录:本项目(D:\datawhale training\trae)
> 作者目标:大三学生,Python 刚入门,三个月后考英语六级(CET-6)。想用"边学边做"的方式,做出一个自己能用的六级背单词手机 App,并能持续加新功能。

---

## 1. 一句话

一个**手机优先的网页 App(后续用 Capacitor 打包成可安装安卓 APK)**:装入全部六级考试大纲词汇,用户主动把每个词归入 熟悉/陌生/不会 三类,并分别复习「陌生」「不会」两个词库。可扩展,后续能长出新功能。

## 2. 目标 & 非目标

**v1 目标(当前里程碑)**
- 全量六级大纲词(约 5000+)一条不少,每条含:英文、音标、词性、中文释义。
- 三态主动归类:熟悉 → 不再出现;陌生 → 进「陌生词库」;不会 → 进「不会词库」。
- 两个复习库 + 复习时可用同一套三键重新归类(词可在区间流动)。
- 进度(每个词当前状态)存手机本地,无需账号。

**v1 非目标(明确砍掉,留给后续)**
- 听力练习、发音播放、听音选义/听写(v2)。
- 词表浏览/搜索(v2)。
- 每日计划/到期提醒、间隔重复算法(v2/v3)。
- 真机 APK 安装包(v3——因为本机尚未安装 Java 与 Android SDK,先跑浏览器版,装了再打包)。

## 3. 可扩展性原则(用户明确要求"后续能继续加功能")

- **数据、状态、界面三层分离**,新增功能 = 新增独立 js 模块并在 index.html 里挂载,不推倒重来。
  - 数据层:全局 `window.CET6_WORDS`(词库,只读)。
  - 状态层:`js/state.js` 封装 localStorage 进度读写,提供统一函数(见 §6)。
  - 界面层:`js/app.js` 负责渲染与点击。
- 词库与进度**解耦**:词库文件可随时被更大的/更新的词表替换,不影响已有进度(key 是单词本身)。
- 每个 js 顶部用一行注释写明"这个文件做什么、以后新功能加在哪"。

## 4. 产品行为细节(v1)

1. 启动首页(桌面/手机宽度都适配):
   - 「开始背新词」入口 + 待分类剩余数;
   - 「复习·陌生」入口 + 数量;
   - 「复习·不会」入口 + 数量;
   - 顶部或角落显示已完成(熟悉)数,给成就感。
2. 卡片页(三种场景共用同一套组件):
   - 先显示**英文 + 音标**,中文释义隐藏;
   - 点击/按钮「显示释义」→ 显示词性 + 中文;
   - 底部三个大按钮:**熟悉 / 陌生 / 不会**;
   - 点击后:熟悉→从所有队列消失并记入完成;陌生/不会→进对应库;自动切下一个词。
3. 复习「陌生」库:队列=所有标为陌生的词。按钮含义同"重新归类":
   - 点「不会」→ 留在/移动到 不会库;
   - 点「陌生」→ 保持陌生(下一个);
   - 点「熟悉」→ 出局(移出复习,记完成)。
4. 复习「不会」库同理;点「陌生」会把它降级移入陌生库。
5. 队列为空时显示鼓励文案(如"陌生库清空啦 🎉 去复习不会的 / 或背新词")。
6. 一个词初次出现顺序:随机;复习库内部:随机顺序(每次进库打乱)。
7. 不做词频加权(留给 v2 的"每日计划")。

## 5. 数据 schema(爬虫产物的唯一契约)

**data/words.json**:顶层为数组,元素:

```json
{ "word": "abandon", "phonetic": "/əˈbændən/", "pos": "vt.", "meaning": "抛弃;放弃" }
```

字段规则:
- `word`:小写英文单词(唯一)。required。
- `phonetic`:音标字符串(美音优先;含 / 斜杠也可)。尽量有;确实没有可留空字符串。
- `pos`:词性,如 `n.` `v.` `adj.`。可空字符串。
- `meaning`:中文释义,多个义项用 `;` 连接。required,不得为空。

**app/js/words.js**:为方便本地与 Capacitor 静态加载、避免 CORS,由同一爬虫生成,内容必须**恰好是**:

```js
window.CET6_WORDS = [ ...同 words.json 的数组... ];
```

(缩进美化与否均可,但必须是合法 JS,变量名 `CET6_WORDS` 大写固定。)

## 6. 状态存储契约

- localStorage key:`cet6_progress_v1`
- 值:对象 `{ "abandon": "familiar" | "unfamiliar" | "dontknow", ... }`
- 未出现的词 = 尚未分类。UI 文案:熟悉/陌生/不会。
- `js/state.js` 需至少提供:`loadState()` `mark(word, category)` `countBy(category)` `getUnclassified()` `getByCategory(category)`。升级/换 key 通过函数收敛,界面不直接碰 localStorage。

## 8. 数据来源规则(重要)

- 只使用**公开/开放许可**的六级词表与词典数据(公开 GitHub 数据集、开放词典如 ECDICT 系、CSV/JSON 直接下载的原始文件优先)。
- **禁止**从需要登录/付费/robots 禁止的站点爬;禁止编造任何释义或音标。
- 首选"一行一条、字段齐全"的现成数据文件;若无全字段,可用两个公开源拼接(词表→释义/音标),并在 DATA_SOURCE.md 如实记录每个字段来自哪里、覆盖缺失情况。
- 网络若在沙箱中被拦,如实报告阻塞点与备选源,不硬凑。
