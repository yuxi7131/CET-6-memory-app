# 六级背单词(学习项目)

给作者自己的 CET-6 背单词手机 App。规格见 [`docs/SPEC.md`](docs/SPEC.md)。

**现在能做什么(v1)**:装入六级词表 → 单词卡片主动归类 **熟悉/陌生/不会** → 分别复习「陌生」「不会」两个词库,复习时允许词在区间流动。进度存浏览器本地。

**怎么跑**:在 `app/` 目录执行 `python -m http.server 8000`,手机/电脑浏览器打开 `http://localhost:8000`(手机需同一 WiFi,访问电脑局域网 IP)。

**路线图**:M1 词表+背单词(v1)→ M2 词表搜索/发音 → M3 打包安卓 APK → M4 听力/每日计划。详见 SPEC。
